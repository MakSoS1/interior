# Blender → Interior AR

1. Откройте сцену Blender → Scene Properties → Units: **Metric, Unit Scale 1.0**.
2. Стройте гарнитур с реальными физическими размерами в метрах. Например: шкаф 600×600×870 мм → `0.6×0.6×0.87`.
3. Разместите кухню в единой сцене: **+X** идёт вправо вдоль стены, **Blender +Z** — вверх, **Blender −Y** — внутрь комнаты (Blender glTF-export автоматически преобразует оси в glTF Y-up).
4. Важно: после экспорта glTF у приложения локальные оси модели **X вправо, Y вверх, Z из стены в комнату**. Подбирайте экспортную ориентацию тестом в 3D-просмотре и при необходимости используйте «180°» в AR.
5. Origins всех частей сохраняйте в реальном общем пространстве кухни. Точка начала гарнитура — левая нижняя точка у стены, высота пола 0.
6. Используйте UV-развёртку и обычные PBR-текстуры BaseColor, Metallic/Roughness, Normal, AO. Текстуры должны быть **встроены** в GLB. Для реалистичной кухни лучше качественные UV, шероховатость и плотность текстур 1k–2k, не сотни мегабайт.
7. File → Export → glTF 2.0 → Format **glTF Binary (.glb)**, Apply Modifiers, Include Materials, Transform +Y Up.
8. Отправьте `.glb` на Android любым способом и откройте «Загрузить GLB». APK не читает `.blend` напрямую.
9. Проверьте физические габариты в предпросмотре; программа никогда не нормализует размеры в AR автоматически.

Для тестовой кухни исходный генератор `scripts/generate_demo.py` не требует Blender и создаёт GLB непосредственно со всеми перечисленными мебельными модулями. Процедурные материалы не заменяют настоящие текстуры для фотографической визуализации.
