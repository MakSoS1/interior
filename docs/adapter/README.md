# Interior AR 0.3 — объекты, группы и естественное освещение

## Перенос из Blender

Установите `interior_ar_export.zip` из локального файла в настройках Blender и включите аддон. Выделите мебель → File → Export → Interior AR (.interior.zip). Режим **One rigid group** сохраняет все детали как единую группу. Режим **Separate collections** экспортирует выбранные коллекции верхнего уровня отдельно, чтобы расставлять их независимо. Поддерживается статическая вычисленная геометрия с модификаторами, PBR-материалами и встроенными текстурами. Исходные объекты, единицы сцены и выделение восстанавливаются после экспорта. Инстансы коллекций предварительно реализуйте; процедурные материалы предварительно запеките в текстуры.

Единицы сцены учитываются явно через scale_length. Если шкаф задан как 60 см, экспортируемая ширина должна получиться 0.60 м. Нельзя определить реальные размеры произвольной модели по внешнему виду. Анимации, камеры и авторские источники света в пакет не переносятся.

## Без Blender

Python 3.11+, стандартная библиотека:

```bash
python adapter/pack_glb.py chair.glb table.glb -o dining_set.interior.zip --name "Dining set"
```

Телефон читает **GLB** и подготовленные **.interior.zip**. Он не читает .blend / .fbx / .obj напрямую: экспортируйте их в GLB в своей программе. Одна GLB-иерархия — одна жёсткая группа; отдельные GLB — отдельно размещаемые группы.

## В приложении

Нажмите «Загрузить GLB», выберите GLB или ZIP. Группы появятся в библиотеке. Откройте любую, проверьте габариты, нажмите «Разместить в AR». Сначала A/B/C задают общую систему координат комнаты. Затем «Добавить объект» добавляет любой предмет из библиотеки; для него также выбираются A/B/C на полу. A — задний левый угол габарита основания, B — направление вправо, C — сторона перед предметом. Всё остаётся в одной системе координат комнаты.

Экземпляры одного GLB независимы: можно продублировать стул, изменить положение/поворот/высоту, убрать экземпляр из комнаты. По умолчанию масштаб 1.000 (реальные метры). Масштаб изменяется только явно; есть возврат 1:1. Сохраняются локальная расстановка и свет. При перезапуске нужно отметить те же физические A/B/C комнаты: JSON не является сохранённой ARCore-картой.

По умолчанию `origin=floor` переносит bbox-min X/Y/Z модели в точку опоры без изменения масштаба. Для выступающей столешницы это край габарита, не скрытая ножка. Для подвесных объектов есть поправка высоты. `origin=authored` в manifest сохраняет авторский ноль модели. Скрытие из библиотеки не повреждает ссылки существующих расстановок.

## Освещение теперь рассчитывается в APK

Реальный ARCore Environmental HDR → SceneView/Filament: направление/RGB основного света, сферические гармоники, отражательная cubemap. Второй встроенный estimator отключён. «Естественный свет» включает −0.55 EV для 3D-мебели и сглаживание по прошедшему времени; ручная коррекция −2…+1 EV сохраняется. NaN и отрицательные значения отвергаются. Интенсивность рассчитывается от постоянной базы, а не многократно умножается на предыдущую.

Небольшая сетка Y-канала камеры читается 2 раза в секунду. Клиппированные окна и почти чёрные пиксели исключаются; коррекция ограничена. Кадры не сохраняются и не отправляются. Камерный фон не затемняется.

Это перенос цели и управляющих параметров офлайн-освещения, **не буквальный экранный фильтр прежнего видео**: экранная маска может создавать ложные тени, скользящие по 3D-поверхности. Здесь свет остаётся частью 3D-сцены. Реальное соответствие освещения квартире требует проверки на совместимом телефоне.

## Безопасность и пределы

Максимум 24 группы, 200 MiB на GLB, 256 MiB на архив/распакованные модели. Весь пакет валидируется перед одной атомарной записью библиотеки: безопасные пути ZIP, единицы m, контрольная сумма, границы чанков GLB и отсутствие внешних URI. Тяжёлые текстуры и геометрия всё равно требуют оптимизации под память GPU. Поддержка каждого glTF-расширения не гарантируется.

AR Optional: без ARCore остаётся библиотека и 3D-просмотр. Обычная MP4-запись кухни не содержит ARCore camera poses / IMU / depth и не заменяет проверку приложения на телефоне. Старый стол не удаляется из камеры. ARCore может принять столешницу за горизонтальную плоскость — A/B/C нужно ставить именно на пол.
