# Проверка Interior AR на физическом телефоне

## Установка

1. В GitHub откройте Actions → Android APK → последний **зелёный** прогон ветки `feat/interior-ar-app`.
2. В артефактах скачайте `interior-ar-debug-apk`, распакуйте `app-debug.apk` и установите.
3. Выберите «Тестовая кухня» и дождитесь 3D-просмотра. Проверочный размер: примерно **2,60 × 2,12 × 0,68 м** (Ш×В×Г).
4. При выборе «Разместить в AR · 1:1» приложение проверяет Google Play Services for AR и запрашивает доступ к камере только для AR.
5. Просканируйте освещённый пол, нажмите **начальный угол** гарнитура и **вторую точку вдоль стены не ближе 50 см**. Измерьте расстояние предварительно рулеткой.
6. После фиксации пройдитесь вдоль гарнитура и обойдите его. Кнопки поправки — шаг 1 см, поворот 5° и 180°. Кнопка «Переставить» позволяет повторно указать точки.
7. Закройте приложение, откройте сохранённый проект и заново откалибруйте две точки: абсолютные координаты ARCore не сохраняются между сессиями.

## Аппаратная совместимость

- Основной сценарий тестов: realme 14 Pro+ (Android 16); альтернативный — Pixel 10 (Android 17).
- Устройства без ARCore по-прежнему должны показывать библиотеку проектов и обычный 3D-просмотр. Наличие Android 16/17 само по себе не гарантирует ARCore.
- Перед началом зафиксируйте версию Android, модель, Play Services for AR, разрешение камеры, статус ARCore, возможность Depth Occlusion.

## Протокол приёмки

| Тест | Метод | Требование |
|---|---|---|
| Запуск без ARCore | Откройте демо в 3D | Нет краша, AR сообщает о недоступности |
| Масштаб | Рулетка 60 см по виртуальному шкафу | Близко к 60 см; ошибки — повод повторить калибровку |
| Выравнивание | Выбрать две точки у стены | Модель следует направлению и остаётся у пола |
| Устойчивость | Отойти на 3 м и вернуться | Anchor не следует за телефоном |
| Трекинг | Закрыть камеру рукой, убрать | UI предупреждает, объект не переносится намеренно |
| Свет | Включить/выключить люстру | Изменяются PBR-материалы/рассеянный свет без сильных вспышек |
| Depth | Провести реальным стулом перед моделью | Если Depth поддерживается — правильное перекрытие |
| Тени | Проверить у пола при освещении | Тень соответствует модели и освещению, без двойного слоя |
| Сохранение | Изменить X/Z/yaw, перезапустить | Проект сохранён, требуется новая ручная калибровка |
| Плохой импорт | Загрузить txt вместо GLB | Понятная ошибка, прежние проекты не исчезают |
| Быстродействие | Проверить кадры / температуру | Без устойчивого перегрева и серьёзных лагов |

## Важные ограничения

- Android-эмулятор и GitHub Actions **не подтверждают** точность ARCore, качество теней и правильность освещения от камеры.
- Встроенный тестовый гарнитур — процедурная геометрия без фотографических текстур, полезная для проверки размещения и отражательных свойств материалов, но не эталон фотореализма.
- В существующей кухне реальный гарнитур будет виден в камере и может перекрывать виртуальный; автоматического удаления старой мебели нет.
- Планировщик комнаты и точное измерение стен через телефон не реализованы: размеры берутся из Blender.
- На официальном списке https://developers.google.com/ar/devices реальный ARCore-статус realme 14 Pro+ нельзя уверенно установить по названию модели; требуется проверка на устройстве.
